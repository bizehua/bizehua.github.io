# 东钢焦电部麦尔兹双膛石灰窑 · 安全生产培训与标准化作业区建设平台

纯静态网站（HTML + CSS + 原生 JS，零依赖），依据《2026年东钢集团"标准化作业区"验收标准》与焦电部石灰作业区实际管理文件建设。

## 快速使用

1. 双击 `index.html` 即可在浏览器打开（推荐 Chrome / Edge / Safari）；
2. 或启动本地服务：`python3 -m http.server 8000`，访问 `http://localhost:8000`；
3. 线上访问：https://maerz-kiln-safety.app.workbuddy.host/ ；
4. 整站打包见本目录旁的 `东钢麦尔兹窑安全培训网站.zip`。

## 功能说明

- **在线模拟考试**：3套试卷（岗位安全基础 / 安全管理人员提升 / 应急处置专项），每套30题，限时30分钟，随机抽题，自动评分，逐题解析，成绩保存于本机浏览器，合格线80分。
- **应急处置卡**：CO中毒、高温灼烫、有限空间、火灾爆炸、触电、机械伤害六类情景，步骤化处置流程，页面可直接打印（A4双面排版）。
- **工艺示意图**：双膛窑燃烧期/蓄热期轮换原理，三类高风险区域热点可点击查看风险特征与管控措施，图例支持按类别筛选。
- **PDF表单**：有限空间作业审批表、隐患排查治理台账、安全培训签到表、安全检查表（中英）、危险作业审批表、应急救援物资台账，字段结构转换自作业区现有台账表单，可直接打印使用。

## 后续扩展后台

站点采用"内容数据分离"结构，便于后续接入后台：

1. 题库、条款、处置卡等内容均存放于 `assets/data/*.json`，后台只需维护 JSON 或提供同结构 API；
2. 页面渲染逻辑集中在 `assets/js/` 各引擎中，接口位置以 `fetch()` 为界，替换为后端地址即可；
3. 全站导航/页脚配置集中在 `assets/js/main.js` 顶部的 `SITE_CONFIG` 与 `NAV_ITEMS`，改一处全站生效；
4. 表单 PDF 可用 `tools/generate_pdfs.py` 按同结构再生成（依赖 reportlab）。

## 说明

- 考试成绩、主题偏好仅存储于本机浏览器 localStorage，不会上传；
- 本站为内部培训与标准化建设资料平台，应急电话以作业区当日公布为准；
- 工艺示意图为原理简化图，具体以现场工艺流程为准。
